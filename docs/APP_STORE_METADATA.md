**当前推荐（2026-08 ASO）**：标题/副标题/关键词见第一节至第三节；原则为 **三处不重复用词**，凑满 160 个被索引字符。

## 五、填写注意事项

| 项目 | 说明 |
|------|------|
| 索引字符 | 仅 **名称 30 + 副标题 30 + 关键词 100** 参与搜索；三处勿重复同一词 |
| 描述前 3 行 | 用户不点「更多」也能看到；草稿已将卖点写在前段 |
| 截图文案 | 与副标题对齐：笔顺递进 · 横竖版 A4 · PDF 打印 / 无笔画楷体可选 |
| 定价 | 描述里未写具体价格；审核备注写清 20 次免费 + 一次性解锁 |
| App Store URL | 上架后替换 `lib/src/config/app_share_config.dart` 与 `website/hp/index.html` 中的搜索链接 |
| 生效时间 | 名称/副标题/关键词改后通常需 **随新版本提交审核**；促销文本可随时改 |
| 观察排名 | 改完后 **24–72 小时** 再看 App 分析 → 来源 → App Store 搜索 |
